# Overview

This was my first finished game and my first real collaborative project shortly after I started learning to code for games. It is not the most advanced project in the portfolio, but it mattered because it made the whole path feel possible.

## What I learned

- importing 3D models
- understanding materials and lighting basics
- building a QTE system
- using Git with other people for the first time

The repository is available on [GitHub](https://github.com/Surue/Wish_You_Were_Beer).
