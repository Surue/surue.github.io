# Overview

Cryptical Path was a production project where I supported level design through a procedural generation pipeline and tools built for designers. The focus was not only the algorithm itself but also the interfaces needed to tune parameters, inspect outcomes, and assemble distinct level parts quickly.

## Main contributions

- dungeon generation algorithms
- tools for tuning and validating generation outcomes
- interfaces that gave designers more control over reusable level parts

More about the project is available on the [Old Skull Games page](https://oldskullgames.com/our-games/cryptical-path/).
